# Md. Tamjid Hossain — Portfolio

This is the modern version of my personal portfolio. I built it to introduce myself as a CSE student and present my education, skills, projects and experience in one responsive website.

## Main features

- Hero and about sections
- Education and skills sections
- Project and experience sections
- Responsive header and footer
- Animated page sections with Framer Motion
- Contact form connected through EmailJS
- Social and contact links

## Technologies used

- React 19
- TypeScript
- Vite
- TanStack Router
- Tailwind CSS
- Framer Motion
- EmailJS
- Lucide React icons

## Project structure

```text
src/
|-- assets/
|-- components/
|-- hooks/
|-- lib/
|-- routes/
|-- router.tsx
`-- styles.css
```

The home route combines separate components for the header, hero, about, education, skills, projects, experience, contact and footer sections.

## Run locally

Node.js and npm are required.

```bash
npm install
npm run dev
```

Open the local address shown in the terminal.

## Other commands

```bash
npm run build
npm run preview
npm run lint
```
